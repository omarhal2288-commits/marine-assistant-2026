# مساعد مارين الذكي

تطبيق Android بسيط لفتح تطبيقاتك المثبتة وتقديم أدوات مساعدة محدودة داخلها، مع تأكيدك قبل الكتابة أو النقر.

## التطبيقات التي يمكن فتحها
- WhatsApp Business
- Instagram
- Snapchat
- TikTok
- Facebook
- ChatGPT

زر ChatGPT يفتح التطبيق فقط؛ لا يربط حسابك أو محادثاتك تلقائياً بواجهة API.

## أدوات المساعدة
- فتح التطبيقات إذا كانت مثبتة.
- فتح إعدادات خدمة المساعدة.
- قراءة النص الذي تسمح واجهة التطبيق بعرضه.
- الكتابة في الحقل المحدد بعد تأكيدك.
- النقر على عنصر عند وجود تطابق نصي واحد واضح وبعد تأكيدك.
- لا توجد إيماءات لمس آلية أو تمرير تلقائي في هذا الإصدار.

## الخصوصية وحدود التشغيل
- لا يطلب التطبيق إذن الإنترنت، ولا يحتوي هذا الإصدار على اتصال بخادم خارجي.
- خدمة إمكانية الوصول مقيّدة بستة تطبيقات محددة، ولا تستقبل أحداث بقية التطبيقات.
- عند تفعيل الخدمة، يمكنها قراءة النصوص وأوصاف العناصر التي تتيحها هذه التطبيقات لخدمات الوصول. بعض التطبيقات قد لا تعرض كل محتواها.
- النص المقروء يبقى مؤقتاً في ذاكرة التطبيق، ويمكن مسحه من زر «مسح النص المقروء من الذاكرة»، كما يُمسح عند إغلاق الخدمة.
- لا تستخدم أداة الكتابة أو النقر لإدخال كلمات مرور أو رموز تحقق أو تنفيذ تحويلات مالية أو حذف محتوى. راجع كل عملية بنفسك.
- لا يوجد تحكم كامل أو مضمون في واجهات التطبيقات، ولا يتم تجاوز تسجيل الدخول أو الحماية.

## البناء
1. افتح تبويب Actions في هذا المستودع.
2. شغّل سير العمل Build Marine Assistant APK.
3. بعد نجاح البناء، نزّل artifact باسم marine-assistant-debug-apk.
4. يحتوي الملف المضغوط على app-debug.apk.

## ملاحظة عن النسخة
هذه نسخة Debug موقعة بمفتاح Android Debug، وليست إصداراً نهائياً منشوراً. إصدار Release قابل للتحديث المستمر يحتاج مفتاح توقيع خاصاً ثابتاً يحفظه مالك التطبيق بأمان؛ لا تضع المفتاح داخل المستودع.
